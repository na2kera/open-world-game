# Wildlands

ブラウザで遊べるオープンワールド・アクションです。広大な地形を歩き、アイテムを集め、村人の依頼を受け、敵と戦い、三つの塔を起動して物語を最後まで進められます。操作は Nintendo Switch Pro コントローラー（Gamepad API）と、キーボード / マウスの両方に対応しています。

ワールドはシードから決定的に生成されます。同じシードなら地形・アイテム・敵キャンプの位置は毎回同じです。セーブはブラウザの localStorage に 1 枠だけ保存されます。

## セットアップ

Node.js 20.19 以上。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。同じコマンドが共有サーバー（ポート 8787）も起動します。コントローラーは、タイトル画面でボタンを一度押すと認識されます。

```bash
npm run build      # 本番ビルド
npm run preview    # ビルド結果の確認
npm test           # ユニットテスト
npm run typecheck  # 型チェック
npm run lint       # ESLint
npm run format     # Prettier
```

`?seed=123` でワールドのシードを固定できます。`?debug` で座標と FPS を表示し、コンソールから `window.__game` を参照できます。

## 遊び方

1. タイトルで「はじめから」を選ぶ。
2. 始まりの里で長老イオリと話す。
3. 三つの古代の塔を探し、螺旋階段を上って頂上の端末を起動する。起動した塔はポーズの「マップ」から移動できる。
4. 三塔のあと、高地の闘技場で禍の王を倒し、里に報告する。
5. 合間にミラ・ソラ・リンの依頼（薬草、キャンプ制圧、祠、リンゴ）を進める。

敵のキャンプは里の周辺には出ません。夜は里の外に浮遊する敵が現れます。死亡すると、最後に訪れた塔・祠・里で復帰します。

## 操作

| 動作            | Switch Pro        | キーボード / マウス                      |
| --------------- | ----------------- | ---------------------------------------- |
| 移動            | 左スティック      | WASD                                     |
| カメラ          | 右スティック      | マウス（画面クリックでポインターロック） |
| 攻撃            | Y                 | 左クリック                               |
| ジャンプ        | X                 | Space                                    |
| 調べる / 決定   | A                 | E / Enter                                |
| 回避 / ダッシュ | B 短押し / 長押し | Ctrl / Shift                             |
| 注目            | ZL                | 右クリック長押し                         |
| 所持品          | −                 | Tab / I                                  |
| ポーズ          | ＋                | Esc                                      |

ポーズメニューに冒険手帳とマップ（起動済みの塔への移動）があります。急な斜面は壁に向かって登れます。スタミナが尽きた泳ぎは陸に戻されます。

## マルチプレイ

`npm run dev` はゲーム（Vite）と WebSocket サーバー（ポート 8787）を一緒に起動します。同じ部屋の人が同じ地形シードを共有し、位置と、拾得・宝箱・撃破・塔の起動を同期します。拾得と宝箱の中身を受け取るのは開けた人だけで、塔は全員の拠点とクエストに反映されます。所持品とセーブは各自のブラウザに残ります。

サーバーが落ちていても約 1 秒で一人用に戻ります。`?offline` で最初から接続しません。部屋は `?room=camp`（英小文字・数字・ハイフン、24 文字まで）、表示名は `?name=イオリ` です。先に入った人のシードが部屋の地形になります。常設の部屋に繋ぐときは `?mp=wss://<worker>/` か、ビルド時の `VITE_MULTIPLAYER_URL` を使います。

弓はポーチの武器から装備します。木の矢を1本消費して、カメラの向き（注目中はその相手）へ飛びます。里の釜では、リンゴ、キノコ、薬草とキノコを料理できます。岩や木に向かって歩くと登って上に乗れます。注目は、地形や岩や木で遮られた相手を掴みません。

### Cloudflare に部屋を置く

`workers/multiplayer.ts` の Durable Object が、部屋のシードと、拾得・宝箱・撃破・塔をストレージに残します。ローカルの `npm run dev` は、この手順を実行しなくても今までどおり動きます。

1. `npx wrangler login`
2. `npm run deploy:multiplayer`
3. 表示された `https://` のホストを `wss://` にして、ゲームの URL に渡す。

```text
http://localhost:5173/?mp=wss://open-world-game.<account>.workers.dev&room=wildlands
```

`?room=` は英小文字・数字・ハイフンで 24 文字までです。ビルド済みのクライアントへ常設の部屋を焼き込むときは、同じ URL を `VITE_MULTIPLAYER_URL` にします。

## 既知の制限

- ヘッドレス環境では描画負荷が高く、実機 GPU でのフレームレートは別途確認が必要です。
- 弓の耐久は射つたびに減ります。矢が無いときは撃てません。
