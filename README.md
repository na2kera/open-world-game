# Wildlands

ブラウザで遊べるオープンワールド・アクションです。広大な地形を歩き、アイテムを集め、村人の依頼を受け、敵と戦い、三つの塔を起動して物語を最後まで進められます。操作は Nintendo Switch Pro コントローラー（Gamepad API）と、キーボード / マウスの両方に対応しています。

ワールドはシードから決定的に生成されます。同じシードなら地形・アイテム・敵キャンプの位置は毎回同じです。セーブはブラウザの localStorage に 1 枠だけ保存されます。

## セットアップ

Node.js 20.19 以上。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。コントローラーは、タイトル画面でボタンを一度押すと認識されます。

```bash
npm run build      # 本番ビルド
npm run preview    # ビルド結果の確認
npm test           # ユニットテスト
npm run typecheck  # 型チェック
npm run lint       # ESLint
npm run format     # Prettier
```

`?seed=123` でワールドのシードを固定できます。`?debug` で座標と FPS を表示し、コンソールから `window.__game` を参照できます。

## 遊び方

1. タイトルで「はじめから」を選ぶ。
2. 始まりの里で長老イオリと話す。
3. 三つの古代の塔を探し、螺旋階段を上って頂上の端末を起動する。起動した塔はポーズの「マップ」から移動できる。
4. 三塔のあと、高地の闘技場で禍の王を倒し、里に報告する。
5. 合間にミラ・ソラ・リンの依頼（薬草、キャンプ制圧、祠、リンゴ）を進める。

敵のキャンプは里の周辺には出ません。夜は里の外に浮遊する敵が現れます。死亡すると、最後に訪れた塔・祠・里で復帰します。

## 操作

| 動作            | Switch Pro        | キーボード / マウス                      |
| --------------- | ----------------- | ---------------------------------------- |
| 移動            | 左スティック      | WASD                                     |
| カメラ          | 右スティック      | マウス（画面クリックでポインターロック） |
| 攻撃            | Y                 | 左クリック                               |
| ジャンプ        | X                 | Space                                    |
| 調べる / 決定   | A                 | E / Enter                                |
| 回避 / ダッシュ | B 短押し / 長押し | Ctrl / Shift                             |
| 注目            | ZL                | 右クリック長押し                         |
| 所持品          | −                 | Tab / I                                  |
| ポーズ          | ＋                | Esc                                      |

ポーズメニューに冒険手帳とマップ（起動済みの塔への移動）があります。急な斜面は壁に向かって登れます。スタミナが尽きた泳ぎは陸に戻されます。

## 構成

| ディレクトリ                          | 役割                                                 |
| ------------------------------------- | ---------------------------------------------------- |
| `src/core`                            | ゲームループ、イベントバス、モード遷移               |
| `src/input`                           | Gamepad API とキーボードを共通のアクションに変換     |
| `src/world`                           | シード付き地形、チャンク LOD、植生、水面、昼夜、足場 |
| `src/player`                          | 移動、スタミナ、アバター、三人称カメラ               |
| `src/items`                           | 所持品、拾得、宝箱、調べる対象                       |
| `src/entities`                        | 敵、キャンプ、NPC                                    |
| `src/combat`                          | コンボ、回避、ロックオン                             |
| `src/quests` `src/story` `src/dialog` | クエスト、本編、会話                                 |
| `src/save`                            | localStorage のセーブ（version 1）                   |
| `src/ui`                              | DOM の HUD、メニュー、会話                           |
| `src/net`                             | マルチプレイ用の伝送インターフェース（未接続）       |

外部の 3D モデルやテクスチャは使っていません。地形・キャラクター・建造物は手続き生成です。

## マルチプレイ

まだサーバーはありません。`src/net/NetTransport.ts` の `NetTransport` と `PlayerSnapshot`、`RemotePlayer` が差し込み口です。ワールドがシード決定的なので、将来は Cloudflare Workers と Durable Objects でプレイヤー位置とワールドイベント（拾得、撃破、塔の起動）だけを同期する想定です。一人用のセーブデータとは別にします。

## 既知の制限

- 敵のロックオンは距離と生存だけを見ていて、地形の遮蔽は判定しません。
- 岩や木の上には乗れません。塔の階段だけが足場です。
- マルチプレイ、弓、料理は未実装です。
- ヘッドレス環境では描画負荷が高く、実機 GPU でのフレームレートは別途確認が必要です。
